# Repository authoring rules

This is a private authoring foundation for a Hungarian AI sales and marketing workshop.
Read CONTRIBUTING.md and standards/material-standard.md before editing course content.
Participant-facing text and copyable business prompts are Hungarian. Paths and machine fields are English.
Use thematic folders. Partner names belong in course/partners.yaml and module partner references.
Use the exact brand name Blackhole Media. Do not add Pegasus branding.
Keep canonical metadata in YAML; do not maintain separate coach copies of lesson content.
Never mark a draft lesson or an untested integration as ready. Do not invent capabilities or credentials.
Keep lesson IDs stable. Update prerequisites, outputs and recovery paths together.
Participant business data, account tokens and real customer records must not be committed.
Run python scripts/validate.py after changes. Generated dist/ files are not source.
Do not publish a participant site or broaden repository visibility without an explicit request.
The reference repository was inspected for patterns only; its issue system and implementation rules are not inherited here.
